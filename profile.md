# Interest profile

Each `##` section is one theme. The text under it is embedded as-is, and the
lines starting with `keywords:` feed the keyword baseline. Edit freely.

## LLM agents and evaluation
Papers on agents built on language models: planning, multi-step task execution,
multi-agent systems, agent harnesses, and especially how to evaluate them —
benchmarks, evaluation methodology, LLM-as-judge reliability, failure analysis,
reproducible agent evals.
keywords: agent, agents, agentic, multi-agent, benchmark, evaluation, evaluating, llm-as-a-judge, judge, harness, trajectory

## Tool use and MCP
Language models calling tools, functions and APIs; Model Context Protocol (MCP)
servers and clients; tool selection, tool-call reliability and security,
prompt injection through tool outputs, computer-use and browser agents.
keywords: tool, tools, tool-use, function calling, mcp, model context protocol, api calls, prompt injection, computer-use, web agent

## Local and small models
Small language models that run on a laptop or single GPU: distillation,
quantization, efficient inference, on-device deployment, and evidence that small
models can match larger ones on practical tasks.
keywords: small language model, slm, quantization, quantized, distillation, on-device, edge, efficient inference, lightweight, 1b, 3b, 7b, 8b

## RAG with evidence
Retrieval-augmented generation that grounds answers in sources: citation and
attribution, faithfulness and hallucination detection, evidence verification,
retrieval quality, and evaluation of grounded answers.
keywords: retrieval-augmented, rag, retrieval, citation, attribution, grounding, grounded, faithfulness, hallucination, fact verification, evidence

## AI for games and player data
AI applied to video games and players: game-playing agents, procedural content
and level generation, NPC dialogue, game design assistance, player modelling,
telemetry and behaviour analytics, churn and engagement prediction.
keywords: game, games, video game, player, players, npc, procedural content, level generation, gameplay, minecraft, esports
